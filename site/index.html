Know what every reward is worth before the timer runs out.

FrameSight puts platinum and ducat values under every card on Warframe's reward screen and on Baro's Ducat Kiosk, then prices your whole collection between missions. Free and open source, native on Linux, Windows and the Steam Deck.

Between missions, everything in one quiet window.

The world's timers, a collection priced to the platinum, and sell orders that match what you actually hold. Dense where it helps, silent everywhere else.

The world at a glance

Open-world cycles, Void Fissures with their relic era, the sortie, the archon hunt and Baro's next visit, read straight from the game's world state.

  • Bounty tiers with the reward table each one pays from
  • Endless mission rotations: A, A, B, C

Your collection, priced

Gear, Prime parts, relics, mods and arcanes on one screen, each with its platinum and ducat value. Filter to what you own, what you have mastered, or what is left to master.

  • Mods and arcanes priced at their actual rank
  • Overframe's best builds on every Warframe and weapon

Listings that match your inventory

Link warframe.market only if you want to. FrameSight flags a listing for an item you no longer hold, or one that oversells what you have, and puts the repair right beside it.

  • List, delist, mark sold and set your online status
  • Optional sync after each inventory read

    You decide what it may read. Before it reads anything.

    FrameSight asks for an access level the first time it opens, and observes nothing until you confirm. Lower it later and everything it no longer permits stops at once.

    ReadsNothing from the game.
    Gives youThe Dashboard, the collection from a snapshot, prices, relics, farming, and warframe.market orders.
    SendsNothing about you. Prices, the item catalogue and world state are downloaded. warframe.market sees you only if you link it.
    ReadsThe screen, and the game's log file EE.log to know when a reward screen opens. Never the game's memory.
    Gives youEverything in Companion, plus the reward overlay and the Ducat Kiosk overlay.
    SendsNothing more than Companion. The screen is read on your machine with Tesseract.
    ReadsEverything in Overlay, plus an account ID and nonce from the Warframe process.
    Gives youAutomatic inventory sync, and owned, missing and mastery marks on every slip, card and kiosk tile.
    SendsThat ID and nonce to mobile.warframe.com's inventory endpoint, and nowhere else.
    At every level: no writing to the game, no automated input, no telemetry.

    Download FrameSight

    The latest release, built for 64-bit Windows and Linux. Pick your system.

    Windows 10 and 11

    One installer, for your user only, so no admin prompt. It carries its own text reader and fetches Microsoft's WebView2 runtime if your PC lacks it.

    Download the installer

    x64-setup.exe

    Before your first mission

    1. SmartScreen warns the first time because the installer is not code-signed. Choose More info, then Run anyway.
    2. Set Warframe's Display Mode to Borderless. In exclusive fullscreen no app can draw over the game.
    3. Pick an access level when FrameSight opens. Nothing observes the game until you confirm.
    FrameSight is developed on Linux. Windows builds are tested, but less often: if something is off, an issue on GitHub helps.

    Fedora 40 and newer

    An .rpm package with a tennoscope command and a desktop entry. Warframe can run through Steam's Proton or Wine.

    Download the .rpm

    x86_64.rpm

    Install it, with the text reader the overlays use

    sudo dnf install ./TennoScope-*.x86_64.rpm tesseract tesseract-langpack-eng
    • Run it from the terminal in the folder you downloaded to.
    • Wine's virtual-desktop mode also needs xwininfo.

    Ubuntu 24.04, Debian 13 and newer

    A .deb package with a tennoscope command and a desktop entry.

    Download the .deb

    amd64.deb

    Install it

    sudo apt install ./TennoScope_*_amd64.deb
    The package needs glibc 2.39. On Ubuntu 22.04 or Debian 12, take the AppImage instead.

    Steam Deck and any 64-bit Linux

    One self-contained file, nothing to install. On the Steam Deck, switch to Desktop Mode first.

    Download the AppImage

    amd64.AppImage

    Make it runnable, then start it

    chmod +x TennoScope_*_amd64.AppImage && ./TennoScope_*_amd64.AppImage
    • Works back to Ubuntu 22.04 and Debian 12.
    • The reward overlay needs tesseract with its English data from your distribution.

    Every build, checksum and changelog is on the GitHub releases page. The reward reader matches English item names, so the game client has to be in English.

    Questions, answered plainly.

    Anything else lives in the repository.

    Does FrameSight modify Warframe or automate anything?

    No. It only reads: the screen and EE.log for the overlays, and, at Full access only, an account ID and nonce from the game process. No access level writes to the game or automates input.

    Does it need Overwolf or an account?

    No. FrameSight is a standalone desktop app with no account and no telemetry. Linking warframe.market is optional and only needed to manage your orders.

    Does it work on Linux and the Steam Deck?

    Yes, it is developed on Linux. It reads Warframe running through Proton or Wine, and the Steam Deck runs the AppImage in Desktop Mode.

    Where do the prices come from?

    From warframe.market. The collection uses a daily summary served by relics.run; the reward screen prices the whole squad's relic pool from the sellers who are in game right now. Ducat values are Baro Ki'Teer's.

    Why doesn't the overlay show up?

    Set Warframe's Display Mode to Borderless: in exclusive fullscreen nothing can draw over the game. The reward reader also needs the game in English, and the access level set to Overlay or Full.

    Is it free?

    Yes, free and open source under the GPL-3.0 license. FrameSight continues TennoScope, created by Deftera186 and its contributors.
